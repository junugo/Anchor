# 📘 Anchor 使用指南（非开发者版）

> 这份指南不需要任何编程基础。跟着做，你就能把 Anchor 跑起来、装好四个客户端、开始用。
> 遇到看不懂的词，先翻文末 [FAQ](#-常见问题)；解决不了再去看开发者向的 [README](../README.md)。

---

## Anchor 是什么？

Anchor 是一位住在你设备里的**数字室友**，帮你照看生活节律。

它在后台悄悄感知你的状态——是在工作、在休息、在娱乐，还是又不知不觉「神游」了——然后：

- **状态对的时候，它完全沉默**，只是替你记下来
- **开始偏离时，它轻轻提醒你**（比如夜深了还在刷视频）
- **到点就寝时间，它认真起来**：屏幕渐渐变灰，把你往床上送

它不会评判你，只说中文短句，像一个关心你的室友。

## 一分钟看懂工作原理

```
你的电脑 / 手机 / 浏览器 / 编辑器   （只负责感知和提醒）
        │  行为数据加密上传（密钥只有你知道）
        ▼
   你自己的服务器                  （统一分析，推断状态）
        │  该沉默时沉默，该提醒时提醒
        ▼
   回到各设备执行：通知 / 灰屏 / 状态栏颜色
```

要点：**服务器是你自己的**，数据不出你的设备生态，没有账号、没有遥测。

## 🌡️ 它会怎么对你？

偏差越大，干预越强；状态符合预期时，系统沉默。

| 你的状态 | Anchor 的反应 | 强度 |
|----------|---------------|------|
| 心流工作 / 好好睡觉 | 静默记录，不打扰 | 🟢 无感 |
| 该睡了还在放松 | 柔和提醒（日落渐变引导） | 🟡 轻 |
| 工作中拿起手机娱乐 | 标准娱乐摩擦（通知/软干预） | 🟠 中 |
| 深夜高刺激浏览 | 硬宵禁（灰屏、浏览器拦截） | 🔴 强 |

同一类提醒有冷却时间，不会连环弹窗烦你。

## 第一步：部署服务器（已有人帮你部署？直接跳到第二步）

你需要一台**能长时间开机的机器**：家里的电脑，或租一台云服务器（VPS）。云服务器更省心，一个月几美元起。

**准备环境**：安装 [Node.js](https://nodejs.org)（≥ 20）和 pnpm：

```bash
npm install -g pnpm
```

> Windows 用户请使用 Git Bash 或 WSL 执行下面的命令。

**1. 拉取代码并安装依赖**

```bash
git clone https://github.com/junugo/Anchor.git
cd Anchor
pnpm install
```

**2. 配置环境变量**

把 `apps/web/.env.example` 复制一份为 `apps/web/.env`，打开编辑三项：

| 配置项 | 填什么 |
|--------|--------|
| `ANCHOR_AI_API_KEY` | AI 密钥（BYOK，自带密钥）。默认走 [DeepSeek 开放平台](https://platform.deepseek.com/) 的 `deepseek-chat`；想换模型再配 `ANCHOR_AI_MODEL` 和 `ANCHOR_AI_BASE_URL`（兼容 OpenAI / Moonshot / 本地 Ollama 等任意 OpenAI 兼容端点）。没有它系统照常记录和推断，只是 AI 聊天、日记分类不可用 |
| `ANCHOR_DATA_KEY` | **自己编一串又长又随机的密码**（建议 32 位以上），这是行为数据的加密密钥，所有客户端都要填同一个。**妥善保存，丢失后旧数据无法解开** |
| `ANCHOR_TZ` | 你的时区，国内用户保持默认 `Asia/Shanghai` 即可 |

**3. 构建并启动**

```bash
pnpm web:build
pnpm web:start
```

启动成功后，浏览器打开 `http://localhost:4000` 能看到 Anchor 界面。

**4. 放行端口**

- **云服务器**：在安全组里放行 TCP `4000` 端口
- **家里电脑**：在系统防火墙里允许 `4000` 端口

之后手机等其它设备就能通过 `http://服务器IP:4000` 访问了。

> 💡 想让服务器开机自启、崩溃自动重启，可以用 pm2 或系统自带的任务计划程序托管 `pnpm web:start`，网上教程很多。

## 第二步：安装四个客户端

到 [Releases 页面](https://github.com/junugo/Anchor/releases) 下载最新版，四选一或全装（装得越多，Anchor 越了解你）：

| 客户端 | 下载文件 | 安装方法 |
|--------|----------|----------|
| 💻 Windows 桌面端 | `anchor-desktop-版本-windows-x64-setup.exe`（安装器）或同名 `-x64.exe`（便携版，免安装） | 双击运行。装好后它住在系统托盘，负责追踪窗口焦点、到点灰屏 |
| 📱 Android | `anchor-mobile-版本-debug.apk` | 传到手机点击安装（需允许「安装未知来源应用」）。负责感知手机屏幕开关、前台应用 |
| 🌐 Chrome 浏览器 | `anchor-chrome-版本.zip` | 解压 zip → 打开 `chrome://extensions` → 开启右上角「开发者模式」→ 点「加载已解压的扩展程序」选解压目录。负责记录网址、宵禁时拦截页面 |
| 📝 VS Code | `anchor-vscode-版本.vsix` | VS Code 扩展面板右上角「⋯」→「从 VSIX 安装…」。负责感知写代码活动 |

## 第三步：让客户端连上服务器

> 🔐 **v2.0.0 起连接方式改为「配对」**，不再需要手动填数据密钥：先在 dashboard 设置密码、生成配对码，再在客户端引导中输入配对码即可。详见 [安全与配对](#-安全与配对)。

四个客户端都**默认连接本机**，如果你把它们和服务器装在同一台电脑上，什么不用改就能用。

装在不同设备上时，在各自设置里填两样东西：

| 客户端 | 设置入口 | 填什么 |
|--------|----------|--------|
| 💻 桌面端 | 系统托盘图标右键 → 设置 | 服务器地址（如 `http://192.168.1.10:4000`）+ 数据密钥 |
| 📱 手机 | 设置页 → 服务器连接 | 同上。和电脑同一 Wi-Fi 时填电脑局域网 IP |
| 🌐 Chrome | 点扩展图标 → 齿轮 → 选项页 | 同上 |
| 📝 VS Code | 设置 → 扩展 → Anchor | 同上（`anchor.serverUrl` / `anchor.dataKey`） |

**数据密钥 = 第一步 `.env` 里的 `ANCHOR_DATA_KEY`，所有设备填同一个。**

怎么确认填对了？服务器启动时会打印 `[ws] 数据密钥指纹: XXXXXXXX`（8 位）。客户端密钥正确，数据就开始流动；填错了，客户端的数据会被静默丢弃（界面上就是「没数据」）。

## 🖥️ 日常使用

打开 `http://服务器IP:4000`，左侧图标栏切换页面：

| 页面 | 干什么用 |
|------|----------|
| 🏠 首页 | 当前状态、今日概况、系统最近在想什么 |
| 🕘 时间轴 | 一天/一周的状态分段回放，鼠标划过能看到每个时段在干什么 |
| 📔 解离日记 | 系统怀疑你「神游」的时段记录，你确认一下，帮它更懂你 |
| 💬 聊天 | 和 AI 数字室友对话，问问「我今天状态怎么样」 |
| 📊 本周复盘 | 每周自动生成的节律总结 |
| 💊 时间胶囊 | 给未来状态不好的自己留句话，Anchor 会在合适时机播放 |
| 🧩 应用 / 网站 | **教 Anchor 认识你的工作软件**——哪些算工作、哪些是娱乐，它判断会更准 |
| ⚙️ 设置 | 作息（上学/工作时段）、日落宵禁时间、服务器信息等 |

各客户端装好后**不用管它们**，在后台静默工作。想暂停就退出客户端；想彻底安静，把宵禁关掉即可。

## 🔐 安全与配对

v2.0.0 起，每个客户端连接服务器都要「配对」——相当于给每台设备发一张通行证，别人就算知道你的服务器地址也连不上、看不到数据。

**第一次使用（或刚升级 v2）**：

1. 打开 dashboard，首次进入按引导**设置管理密码**
2. 进入「设置」页，点**生成配对码**
3. 打开要配对的客户端，走引导输入配对码，完成

配对一次即可，之后客户端自动保持连接。**不需要再手动填数据密钥**——密钥在配对时自动下发，无感。

> 从 v1 升级：请先升级服务器（见 README 的 v2.0.0 升级说明），再依次升级四个客户端并重新配对。

## 🔄 更新

| 端 | 怎么更新 |
|----|----------|
| 🖥️ 服务器 | 在服务器上运行 `bash scripts/update.sh`；或打开 dashboard，顶部出现更新横幅时点「更新」 |
| 💻 桌面端 | 系统托盘图标右键 → 检查更新，有新版本按提示一键更新 |
| 📱 手机 | 设置页 → 检查更新，按提示下载安装 |
| 🌐 Chrome | 出新版本时扩展会提示，按提示重新加载 |
| 📝 VS Code | 出新版本时扩展会提示，按提示重新安装 VSIX |

更新前建议先备份服务器数据库（复制 `anchor.db` 文件前先执行 `sqlite3 anchor.db 'PRAGMA wal_checkpoint(TRUNCATE);'`）。

## ❓ 常见问题

**我的数据存在哪？安全吗？**
都在你自己服务器的本地数据库里（一个 SQLite 文件），客户端上传前会加密。没有账号体系、没有遥测、没有任何第三方会拿到你的数据。

**连不上服务器怎么办？**
依次检查：① 服务器还在运行吗（`pnpm web:start` 的窗口别关）；② 地址对不对、带不带 `:4000`；③ 手机和服务器在同一网络吗；④ 防火墙/安全组放行 4000 了吗。手机用 USB 连电脑调试时，可以运行 `adb reverse tcp:4000 tcp:4000` 直连本机。

**装好了却没有数据？**
九成是数据密钥填错了。核对：服务器启动日志里的 `[ws] 数据密钥指纹` 与客户端配置是否同源——四个客户端必须填同一个 `ANCHOR_DATA_KEY`。

**它会不会一直弹窗烦我？**
不会。状态对时系统沉默；同一类提醒有 5 分钟冷却，重复提醒按 15→30→60 分钟逐步退避；只有真正夜深了还不停下，宵禁才会升级成硬干预。

**状态判断错了怎么办？**
偶发误判很正常，它会结合后续信号自动修正。如果某类应用总被认错，到「应用 / 网站」页调整分类即可。日记页的确认也在帮它校准。

**没有 AI 密钥能用吗？**
能。状态记录、时间轴、宵禁这些核心功能不依赖 AI；只是 AI 聊天、日记分类、每周分析会缺席。`ANCHOR_AI_API_KEY` 支持 BYOK——DeepSeek、OpenAI、Moonshot、本地 Ollama 等任意 OpenAI 兼容端点都可以。

**FocusLayer 是什么？装的时候看到了这个词。**
一个可选的增强组件，没有它 Anchor 的所有核心功能照常工作，可以无视。

**必须 24 小时开着服务器吗？**
服务器关机的时段，客户端的数据传不上去，那段时间就是空白。建议服务器常开；客户端随用随开，不开只是少一路感知。
