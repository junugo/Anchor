# Anchor — 项目章程

> 版本：1.0 | 日期：2026-08-07 | 作者：junugo

---

## 1. 项目愿景（Why）

Anchor 的存在是为了帮助独立工作者同时实现三件事：

1. **节律自治** — 稳定的昼夜节律，睡眠/工作/休息有规律，不靠意志力硬撑
2. **自我管理** — 在没有外部约束的情况下，自主管理生活节奏，做自己生活的 PM
3. **解离预防** — 识别并打断「刷手机→发呆→愧疚」的解离循环，保持对当下时间的感知

**三年后，一个成功使用 Anchor 的人**：拥有稳定的昼夜节律，能够在没有外部压力的情况下自主管理自己的时间节奏，不再陷入无意识的解离状态，对自己每一天的时间有清晰的感知与掌控。

## 3. 功能范围（What）

### 3.1 V1 核心模块（必须上线）

| 模块 | 核心价值 | 关键特性 |
|------|----------|----------|
| **多客户端行为追踪** | 系统感知的基础，没有它一切无从谈起 | app/进程/焦点/URL/键盘活动，多端加密上报服务器，统一分析 |
| **状态推断引擎** | 服务器综合多端数据，推断当前用户状态 | dissociating / working / entertaining / resting / transitioning |
| **日总结与规划** | 帮助用户对自己的时间建立感知 | 每日行为总结、预测、AI 辅助规划 |
| **数字宵禁引擎** | 节律自治的执行层 | T-60/T-30/T-0 渐进灰屏、摩擦、硬宵禁 |
| **解离缓冲层** | 解离预防的核心 | 被动行为网络 + 推断 + 解离日记 + 时间锚注入 |
| **节律重建器** | 渐进修正生物钟 | 15分钟/天睡眠校正、体感唤醒验证（摇一摇）|
| **单人问责系统** | 自我管理的镜子 | 时间胶囊录制、结构化复盘、生命救援协议 |
| **智能干预引擎** | 在正确的时机以正确的力度介入 | 根据状态偏差动态选择：被动感知 / 轻干预 / 强干预 / 硬宵禁 |

### 3.2 明确 Out of Scope

- 多用户 / 账户系统 / 认证授权
- 社交 / 分享 / 排行榜 / 社区功能
- FocusLayer 强依赖（FocusLayer 是可选增强）
- 云端 SaaS 化
- 公开 API

### 3.3 FocusLayer 集成边界

FocusLayer 是**可选集成**，不是依赖：
- 功能**启用**时：Anchor 主动调用 FocusLayer REST API
- FocusLayer **离线**时：优雅降级，核心功能 100% 可用
- 功能**关闭**时：Anchor 完全独立，无任何 FocusLayer 代码路径

## 4. 技术架构与约束（How）

### 4.1 技术选型（已锁定）

| 层 | 技术 | 说明 |
|----|------|------|
| 服务器 | Next.js 15 App Router + 自定义 `server.ts` | port 4000，WebSocket `/ws` |
| Desktop 客户端 | Rust + Slint 原生守护进程 | Windows 兼容，单文件 exe，**非 Electron，非 Tauri** |
| Mobile 客户端 | Android 原生 Kotlin + Jetpack Compose | 非 Flutter，非 React Native |
| 浏览器客户端 | Chrome Extension MV3 | |
| 编辑器客户端 | VS Code Extension | |
| 数据库 | SQLite via `better-sqlite3` + `drizzle-orm` | |
| AI | DeepSeek API (`deepseek-chat`) | |
| 构建 | pnpm workspaces + Turborepo | |

### 4.2 数据架构原则

- **服务器为可信端**，负责总体决策
- 所有客户端行为数据 **AES-256-GCM 加密上传**（上行行为数据加密，交互/控制消息明文；统一密钥覆盖机制，见 `packages/utils/src/crypto.ts`）
- 各客户端**数据互通**，由服务器统一分析推断
- 客户端角色：采集器 + 执行器
- 服务器角色：推断引擎 + 决策中心 + 日总结 + 规划预测
- 单用户：`user_id = 'default'`，无 auth

### 4.3 关键运行时约束

- 决策引擎冷却：同类型决策最小间隔 5 分钟；动作分发冷却 soft/hard 10–15 分钟，notify 按 15→30→60 分钟指数退避
- 周期 tick（`server.ts`）：**5 分钟完整 tick**（pipeline 推断 + AI 每日维护 + 跨日归档/日记分类 + 周日每周分析）+ **1 分钟轻量 tick** + **每小时**解离日记候选
- `behavior_logs` 永久保留，不自动清除
- 启动时自动执行数据库迁移

### 4.4 Monorepo 结构

```

├── apps/
│   ├── web/          — 服务器主脑（Next.js 15 + WebSocket，port 4000）
│   ├── desktop-rs/   — Rust + Slint 原生守护进程（窗口焦点追踪）
│   ├── chrome-ext/   — Chrome MV3 扩展（URL/宵禁灰屏）
```

## 5. 用户体验与交互基准（Look & Feel）

> 完整设计语言规范见 [docs/superpowers/specs/2026-06-13-design-language.md](superpowers/specs/2026-06-13-design-language.md)，适用于所有客户端（Web、Desktop、Mobile、Chrome Extension、VS Code Extension）。

### 5.1 视觉风格：工具感 × 温暖

- **色调**：暖灰底色（`#f5f0eb`），强调橙褐（`#c0622a`），深色模式 `#1c1814`
- **密度**：工具优先，信息紧凑，类 Linear / Raycast 密度
- **字体**：`system-ui`，无艺术字体，保持工具感
- **图标**：Lucide Icons，全平台一致
- **动效**：功能性，100–200ms，不做装饰性动画
- **导航**：Web / Desktop 左侧图标栏（48px）；Mobile 底部 Dock（56px）

### 5.2 智能干预策略

干预强度**动态匹配**用户当前状态与预期状态的偏差：

| 用户状态 | 预期状态 | 干预级别 | 表现 |
|----------|----------|----------|------|
| 心流办公中 | 办公 | **被动感知** | 静默记录，零打扰 |
| 放松休息 | 该睡觉了 | **轻干预** | 柔和提醒，渐进灰屏 |
| 工作中突然拿起手机 | 应在工作 | **强干预** | 立即拉回，摩擦/震动 |
| 深夜高刺激浏览 | 宵禁时间 | **硬宵禁** | 强制执行，不可绕过 |

**核心原则**：偏差越大、持续越久 → 干预越强。状态符合预期时系统保持沉默。

### 5.3 AI 对话基调

- **角色**：温暖、不评判的数字室友
- **语言**：中文，每条消息 ≤80 字
- **优先级**：体感优先（「你已经坐了3小时了」），而非数据优先
- **禁止**：「你应该」「你必须」等命令式语气
- **允许**：关心式提问、轻柔的时间锚定（「现在是凌晨1点了」）
- **实现**：DeepSeek API，role card 独立维护于服务器

## 7. 约束与风险

| 约束/风险 | 描述 | 应对 |
|-----------|------|------|
| 单开发者 | 所有开发由一人完成 | 优先核心模块，快速迭代 |
| Windows 兼容 | 主要运行环境为 Windows 10 | Rust + Slint 覆盖 |
| 数据安全 | 行为数据、日记属于高度私人数据 | 加密传输，数据不离开个人设备生态 |
| AI 依赖 | DeepSeek API 可能有延迟或宕机 | 降级为预设规则推断，AI 为增强而非必需 |
