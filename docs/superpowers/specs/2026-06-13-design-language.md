# Anchor 设计语言规范

> 版本：1.0 | 日期：2026-06-13 | 状态：已确认

---

## 1. 设计原则

### 核心定位

**工具感优先，兼具温暖。** Anchor 是个人生活管理工具，界面应高效、信息密度合理，不做成艺术感或日记感的视觉风格。同时通过暖色调避免冷硬的控制台观感。

### 三条基准

1. **工具感**：信息密实，间距紧凑，操作路径清晰；类 Linear / Raycast 密度
2. **温暖**：暖灰底色，橙褐强调色，不用纯白纯黑
3. **克制**：只在关键时刻出现视觉噪音，正常状态系统保持沉默

## 2. 色彩系统

### 2.1 浅色模式（主模式）

| 令牌名 | 色值 | 用途 |
|--------|------|------|
| `--bg` | `#f5f0eb` | 页面底色（暖灰，略带棕调） |
| `--surface` | `#ffffff` | 卡片、面板表面 |
| `--surface-raised` | `#faf7f4` | 悬浮层、下拉菜单 |
| `--border` | `#e0d9d0` | 边框、分割线 |
| `--border-subtle` | `#ede8e2` | 次要分割线 |
| `--text-primary` | `#1a1410` | 主要文字 |
| `--text-secondary` | `#6b6560` | 辅助文字、标签 |
| `--text-disabled` | `#b0a89e` | 禁用状态 |
| `--accent` | `#c0622a` | 主操作、强调、focus 状态 |
| `--accent-hover` | `#a8531f` | 强调色悬停态 |
| `--accent-muted` | `#f0e4da` | 强调色浅背景（标签、高亮） |

### 2.2 深色模式（黑夜模式）

| 令牌名 | 色值 | 用途 |
|--------|------|------|
| `--bg` | `#1c1814` | 页面底色（深暖棕） |
| `--surface` | `#252018` | 卡片、面板 |
| `--surface-raised` | `#2e2820` | 悬浮层 |
| `--border` | `#3a3228` | 边框 |
| `--border-subtle` | `#302820` | 次要边框 |
| `--text-primary` | `#f0ebe4` | 主要文字 |
| `--text-secondary` | `#9e978e` | 辅助文字 |
| `--text-disabled` | `#5a5550` | 禁用状态 |
| `--accent` | `#c0622a` | 强调色（与浅色保持一致） |
| `--accent-hover` | `#d4703a` | 深色模式下悬停态稍亮 |
| `--accent-muted` | `#3a2218` | 强调色浅背景 |

**切换触发**：根据系统 `prefers-color-scheme`，或用户手动切换（设置中提供）。

### 2.3 干预强度 × 语义色彩

干预颜色不是装饰，是系统状态的直接编码。任何表示干预等级的 UI 元素都使用以下颜色，不混用。

| 等级 | 颜色 | 色值（亮/暗） | 触发场景 |
|------|------|-------------|----------|
| **被动感知** | 绿色 | `#22863a` / `#3fb950` | 状态符合预期，系统沉默 |
| **轻干预** | 黄色 | `#b08800` / `#e3b341` | 轻微偏离，柔和提醒 |
| **强干预** | 橙色 | `#c0622a` / `#d4703a` | 明显偏离，积极干预 |
| **硬宵禁** | 红色 | `#cf222e` / `#ff7b72` | 宵禁时间，强制执行 |
| **sleep** | 深蓝 | `#1e3a8a` / `#60a5fa` | 睡眠中，静默安睡 |

## 3. 排版

### 字体

```css
font-family: system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
```

**不使用**任何外部字体或艺术感字体。系统字体在各平台上均表现为工具感。

### 层级

| 级别 | 大小 | 字重 | 用途 |
|------|------|------|------|
| 标题 H1 | 18px | 600 | 页面大标题 |
| 标题 H2 | 15px | 600 | 区块标题 |
| 标题 H3 | 13px | 500 | 卡片标题、列表组标题 |
| 正文 | 14px | 400 | 主要内容 |
| 辅助文字 | 13px | 400 | 描述、说明 |
| 小标签 | 12px | 500 | 元数据、时间戳、标签 |
| 微型 | 11px | 400 | 角标、次要说明 |

**行高**：正文 1.5，标题 1.3，单行标签 1.0。

## 4. 间距与圆角

### 间距系统（基于 4px）

| 令牌 | 值 | 用途 |
|------|----|------|
| `--space-1` | 4px | 内联元素间距 |
| `--space-2` | 8px | 组件内部紧凑间距 |
| `--space-3` | 12px | 列表项、卡片内边距（紧） |
| `--space-4` | 16px | 卡片内边距（标准） |
| `--space-5` | 20px | 区块间距 |
| `--space-6` | 24px | 页面边距 |
| `--space-8` | 32px | 大区块间距 |

### 圆角

| 令牌 | 值 | 用途 |
|------|----|------|
| `--radius-sm` | 4px | 标签、小按钮 |
| `--radius-md` | 6px | 输入框、普通按钮 |
| `--radius-lg` | 8px | 卡片、面板 |
| `--radius-xl` | 12px | 模态框、浮层 |

**原则**：不使用 `border-radius: 50%` 做圆形元素（除头像）；保持工具感，不做过度圆润。

## 5. 图标

使用 [Lucide Icons](https://lucide.dev/) — 线条图标，干净、工具感强，与 system-ui 字体配套。

| 场景 | 尺寸 |
|------|------|
| 导航图标 | 20px |
| 内联操作图标 | 16px |
| 状态图标（卡片） | 14px |
| 微型指示图标 | 12px |

图标颜色跟随文字颜色令牌，不单独设置颜色。状态图标使用干预色彩系统（§2.3）。

## 6. 导航结构

### 6.1 Web / Desktop（左侧图标栏）

```
┌──┬────────────────────────────────┐
│  │  页面标题                        │
│🏠│──────────────────────────────  │
│💬│                                 │
│📖│          主内容区                 │
│⚙️│                                 │
│  │                                 │
└──┴────────────────────────────────┘
```

- 宽度：48px 固定
- 图标：20px，居中
- 当前页：`--accent` 色图标 + 左侧 2px `--accent` 色激活条
- 非当前页：`--text-secondary` 色图标，hover 变 `--text-primary`
- 底部固定放置设置图标

### 6.2 Mobile（底部 Dock）

```
┌──────────────────────────────────┐
│                                  │
│          主内容区                  │
│                                  │
├──────────────────────────────────┤
│  🏠    💬    📖    ⚙️            │
└──────────────────────────────────┘
```

- 高度：56px（含安全区）
- 4 个主导航项，等宽分布
- 当前项：`--accent` 色图标，下方 2px 激活点
- 图标上方不显示文字标签（空间不够，图标语义够用）

### 导航项目映射

| 图标 | 页面 | 路由 |
|------|------|------|
| 📊（BarChart） | 仪表盘 | `/` |
| 💬（MessageCircle） | 对话 | `/chat` |
| 📖（BookOpen） | 解离日记 | `/diary` |
| ⚙️（Settings） | 设置 | `/settings` |

## 7. 核心组件规范

### 7.1 状态卡片（StatCard）

```
┌────────────────────────┐
│ LABEL               12px, text-secondary, uppercase │
│ VALUE               22px, 600, 语义色               │
└────────────────────────┘
```

- 背景：`--surface`
- 边框：1px `--border`
- 圆角：`--radius-lg`（8px）
- 内边距：16px 20px

### 7.2 列表项（List Item）

```
┌─────────────────────────────────────────────┐
│ [图标]  主标题                          › │
│         辅助说明（可选）                    │
└─────────────────────────────────────────────┘
```

- 高度：48px（无辅助说明）/ 60px（有辅助说明）
- 背景：`--surface`，hover `--surface-raised`
- 边框：1px `--border`，相邻项共用边框（不叠加）
- 第一项：`border-radius: --radius-lg --radius-lg 0 0`
- 最后项：`border-radius: 0 0 --radius-lg --radius-lg`

### 7.3 按钮

| 类型 | 背景 | 文字色 | 用途 |
|------|------|--------|------|
| Primary | `--accent` | white | 主操作（发送、确认） |
| Secondary | `--surface` + `--border` | `--text-primary` | 次要操作 |
| Ghost | transparent | `--text-secondary` | 导航类操作 |
| Danger | `#cf222e` | white | 删除、宵禁强制 |

高度：32px（默认）/ 28px（紧凑）；圆角：`--radius-md`；内边距：0 12px。

### 7.4 输入框

- 背景：`--surface`
- 边框：1px `--border`，focus 时 1px `--accent`
- 圆角：`--radius-md`
- 内边距：8px 12px
- placeholder 颜色：`--text-disabled`

## 8. 动效

**原则**：功能性动效，非装饰性。时长短，不拖延用户操作。

| 场景 | 时长 | 缓动 |
|------|------|------|
| 悬停状态变化 | 100ms | linear |
| 面板展开/收起 | 150ms | ease-out |
| 页面切换 | 200ms | ease-in-out |
| 干预出现（灰屏等） | 800ms | ease-in（渐进感） |
| 宵禁硬遮罩 | 0ms | 无动效（立即） |

不使用弹性（spring）动画或过度缓动。

---

## 9. 空状态与加载态

### 空状态

- 文字：`--text-disabled`，居中，14px
- 图标：可选，20px，`--text-disabled`
- 不使用插画或大图（保持工具感）

### 加载态

- 骨架屏：`--border` 色块，无动画（避免闪烁干扰）
- 内联加载（如发送按钮）：spinner 替换图标，24px，`--text-secondary`

## 10. 适用范围说明

| 平台 | 适用程度 |
|------|----------|
| Web（Next.js，主界面） | **完全适用**，本规范的设计原点 |
| Desktop（Electron） | 完全适用，导航结构用左侧图标栏 |
| Mobile（Android 原生 Kotlin + Jetpack Compose） | 色彩、排版、间距完全适用；导航用底部 Dock；组件为 Compose 原生实现 |
| Chrome Extension | 色彩适用；布局受 popup 宽度限制（320px），列表项高度可压缩 |
| VS Code Extension | 遵循 VS Code 主题机制，color token 映射到 VS Code CSS 变量 |
